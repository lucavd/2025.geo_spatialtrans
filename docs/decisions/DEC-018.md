# Decisione

Il preset dello stroma del tumore del colon contiene epiteliale (41 %), fibroblasti (33 %), immunitario (19 %) ed endoteliale (8 %), le quote misurate sulle cinque aree di stroma desmoplastico; l'epitelio è qualificato «tumorale» per l'istologia dell'area ([DEC-014](/decisions/DEC-014.md)). I riferimenti restano provvisori finché non si scelgono aree di stroma puro (BL-149, BL-018).
