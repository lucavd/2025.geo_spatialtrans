# Decisione

I riferimenti per tipo cellulare dei sei tessuti (frazione, densita', area e forma del nucleo, territorio, rapporto nucleo/territorio; righe B-161…B-185 di `docs/BIO_REFERENCES.md`) sono calcolati con le etichette del criterio corretto PH-1 (`tools/R6_relabel.py`: arricchimento ipergeometrico dei 50 geni piu' differenziali di ogni cluster negli insiemi di marcatori PanglaoDB, tipo = insieme con la p minima se p < 0.01 / numero di tipi). Le etichette del criterio pre-registrato restano nei file per il confronto, non sono riferimenti.
