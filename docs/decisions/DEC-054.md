# Decisione

2. Con `frame_open = TRUE` (aree ritagliate da un tessuto che continua oltre il riquadro) l'arrivo di un trascritto della seconda coda si ripiega nel riquadro per riflessione ripetuta sui lati; la prima coda e le sfocature restano come in S2.3 (risultati di S2.3 identici, G-4 c).
